# Collection Lineage Skill Family

Skills that find which CMR collections were used to produce a given collection (its parents, inputs, and related products), and record that lineage as UMM-C MetadataAssociations and as CSV.

## Skills

| Skill | Role | Depends on |
|---|---|---|
| `Collection_ATBD_Analysis_Skill` | Parses ATBDs for algorithm descriptions, inputs, outputs and processing specifications. | Base for the lineage skills below |
| `Collection_Lineage_via_ATBD_Skill` | Discovers lineage from ATBD and User Guide evidence, with CMR validation. | `Collection_ATBD_Analysis_Skill` |
| `Collection_Lineage_Generation_Skill` | Defines the lineage relationship types and generates UMM-C v1.18.6 MetadataAssociations. | `Collection_Lineage_via_ATBD_Skill`, `Collection_ATBD_Analysis_Skill` |
| `Collection_Lineage_CSV_Export_Skill` | Writes lineage as one CSV row per relationship, with a rule-based confidence level and an optional evidence sidecar. | `Collection_Lineage_via_ATBD_Skill`, `Collection_Lineage_Generation_Skill` |

Lineage discovery flows from the ATBD analysis into the two output skills. The CSV and the UMM-C output come from the same classification, so their fields match.

## Folders

- `skills/`: the skill definitions above.
- `notebooks/`: Jupyter notebooks that implement these skills (`Collection_Lineage_UMM_C_Export`, `ESDIS_Collection_Lineage_Discovery`, `ESDIS_Collections_Lineage_with_Earthdata_MCP`).
- `reports/`: analysis reports and UMM-C MetadataAssociation JSON for individual collections.
- `metrics/`: lineage CSV files and their evidence JSON sidecars generated by these skills.
